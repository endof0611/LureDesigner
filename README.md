# 🐟 미노우 루어 디자이너 - 사용 설명서

## 개요

미노우 루어 디자이너는 웹 브라우저에서 실행되는 미노우 루어 설계 도구입니다. 측면(Side)과 상면(Top) 두 가지 시점에서 루어의 외형을 편집하고, 물리 기반의 액션 예측까지 확인할 수 있습니다. 별도 설치 없이 HTML 파일 하나로 PC, 태블릿, 스마트폰에서 모두 사용 가능합니다.

## 화면 구성

### 상단 헤더
| 버튼 | 기능 |
|------|------|
| ☰ | 사이드바 열기/닫기 (모바일) |
| 📐 크기맞춤 | 측면/상면 길이를 기준 뷰에 맞춰 동기화 |
| ↺ 초기화 | 선택한 프리셋 형상으로 되돌림 |
| ⌫ 실행취소 | 이전 상태로 복원 (최대 40단계, 프리셋 전환·대칭·립·웨이트 설정 포함) |
| 🖨 인쇄 | 측면·상면을 실제 크기(1:1)로 인쇄 (230mm 루어 → 종이에 230mm). A4, 루어가 190mm보다 길면 가로 방향. 50mm 눈금자와 치수 포함 |
| ⬇ SVG | 현재 루어 형상을 SVG 코드로 내보내기 |

### 캔버스 영역
화면 중앙에 측면 뷰(위)와 상면 뷰(아래)가 나란히 배치됩니다.

- **흰색 배경**에 **검정 외곽선**으로 루어가 표시됩니다
- **그리드**: 보조선 1mm, 주선 1cm 간격 (코끝 기준 정렬), 항상 표시. 루어 안쪽에도 눈금이 비쳐 보입니다. 외곽선 두께는 1.5로 고정
- **기준선**: 세로선은 코끝 위치, 가로선은 중심축
- 측면과 상면의 **코끝(앞부분) 위치는 항상 정렬**되어 길이 비교가 용이합니다
- 각 뷰 **오른쪽 위**에 현재 루어의 치수가 실시간으로 표시됩니다 (측면: 길이·최대 높이, 상면: 길이·최대 폭, 0.1mm 단위)
- 길이·높이·폭은 컨트롤 포인트가 아니라 **화면에 그려진 곡선 외곽선** 기준입니다 (꼬리 끝면은 곡선이 포인트보다 1~2mm 둥글게 나가므로)

## 사이드바 메뉴 (접기/펼치기)

루어 프리셋 메뉴는 펼쳐진 상태로, 나머지 메뉴는 접힌 상태로 시작하며 제목을 클릭하면 펼치거나 접을 수 있습니다.
작업 순서대로 배치되어 있습니다: 루어 프리셋 → 바디 형태 → 립 → 파츠 → 웨이트 → 소재·부속 → 화면 설정(대칭 · 표시) → 📊 액션 예측 → 🎯 실측 보정.

### 루어 프리셋 (최상단)
루어 타입(**빅게임 / 농어 / 기타**)을 고른 뒤, 그 안의 대표 형상(빅게임 8가지, 농어·기타 각 3가지) 중 하나를 선택하면 해당 형상이 화면에 표시됩니다. 표시된 형상은 일반 편집과 똑같이 포인트·슬라이더로 자유롭게 수정할 수 있습니다.

프리셋은 목록에 코드로 표시됩니다: 빅게임 **BG**, 농어 **MN**, 기타 **ET** + 목록 순서 번호(001~). 이름 옆 설명은 그대로입니다.

| 타입 | 프리셋 코드 (원래 이름) | 형태 | 기본 동작 |
|------|--------|------|-----------|
| 빅게임 | BG001 (전갱이) | 다이빙 펜슬 180mm, 깊은 체고 | 플로팅, 꼬리 숙인 자세 |
| 빅게임 | BG002 (날치) | 롱 펜슬 200mm, 슬림 | 플로팅, 꼬리 숙인 자세 |
| 빅게임 | BG003 (라피도) | 마리아 롤링 다이빙 펜슬, 200mm 기준 (230mm로 늘리면 F230과 같은 100g) | 플로팅, 꼬리 숙인 자세 |
| 빅게임 | BG004 (레가토) | 마리아 플랫 사이드 다이빙 펜슬, 200mm 기준 | 플로팅, 수평 자세 |
| 빅게임 | BG005 (Type1) | 캡틴베이트 슬림 다이빙 펜슬, 200mm 기준 (뾰족한 머리) | 플로팅, 꼬리 숙인 자세 |
| 빅게임 | BG006 (Type2) | 캡틴베이트 다이빙 펜슬, 200mm 기준 (높은 이마, 꼬리까지 깊은 배) | 플로팅, 꼬리 숙인 자세 |
| 빅게임 | BG007 (Type3) | 캡틴베이트 다이빙 펜슬, 200mm 기준 (세 가지 중 체고가 가장 높음) | 플로팅, 꼬리 숙인 자세 |
| 빅게임 | BG008 (포퍼) | 컵 페이스 160mm | 플로팅, 꼬리 숙인 자세 |
| 농어 | MN001 (립리스 미노우) | 슬랜트 헤드 125mm (립 없이 비스듬한 머리 앞면, 턱 끝 라인 아이) | 플로팅, 수평 자세 |
| 농어 | MN002 (바이브레이션) | 립리스 75mm, 등 쪽 라인 아이 | 싱킹 |
| 농어 | MN003 (싱킹 펜슬) | 슬림 100mm | 싱킹, 수평 자세 |
| 기타 | ET001 (크랭크베이트) | 배스용 팻 바디 60mm, 립 | 플로팅 |
| 기타 | ET002 (톱워터 펜슬) | 워킹 베이트 110mm, 후방 웨이트 | 플로팅, 꼬리 숙인 자세 |
| 기타 | ET003 (저크베이트) | 서스펜드 100mm, 립 | 서스펜딩, 수평 자세 |

> 라피도·레가토와 캡틴베이트 펜슬 3종은 200mm 기준 형상이며, **비율 유지**가 켜진 상태로 불러옵니다. 길이를 160·230mm 등으로 바꾸면 높이·폭·파츠가 같은 비율로, 웨이트·훅 무게는 부피(길이³)에 비례해 바뀌어 같은 루어의 다른 사이즈처럼 동작합니다.
> 프리셋 외곽선은 24~26개 포인트로 표현합니다. 측정 지점이 적은 프리셋은 설계값을 그대로 지나는 단조 3차 보간으로 지점을 늘려 선이 자연스럽게 이어집니다. 두 루어 모두 관통 와이어 축(라인 아이→꼬리 아이)을 기준으로 측정했습니다. 라피도는 실물 F230 측면 사진에서 외곽선을 추출하고, 상면은 실물 상면 사진처럼 머리가 넓고 뭉툭하며 폭이 거의 일정하다가 꼬리 쪽에서만 좁아지게 만들었고(최대 폭 27~29mm @230mm), 230mm에서 몸통 100g(훅 제외), 훅 아이당 10g(권장 싱글 8~11g + DAEN #9 링)이 되도록 맞췄습니다. 정지 자세는 공개 자료가 없어 일반적인 다이빙 펜슬(꼬리 숙임 약 35°)로 가정했습니다.
> 레가토는 실물 F190 사진(측면·상면)에서 외곽선을 추출했습니다. 라피도와 달리 등은 끝까지 높고 배가 꼬리 쪽으로 올라가, 꼬리가 라인 아이보다 위에 있습니다. F190 60g을 200mm로 환산한 70g에서 플로팅·수평 정지가 되도록 맞췄습니다(물에 띄운 사진과 일치).
> 캡틴베이트 펜슬 3종(Type1~3)은 측면·상면 사진(양쪽 면 평균)에서 사진에 그은 관통 와이어 축을 기준으로 외곽선을 추출해 30개 포인트로 표현했습니다. 무게·자세 자료가 없어 200mm에서 약 70g(Type1)·89g(Type2)·92g(Type3), 꼬리 숙임 약 20°의 일반적인 플로팅 다이빙 펜슬로 가정했습니다.
> 프리셋은 형상과 함께 립, 소재 밀도, 웨이트(무게·위치), **단면 형태**, 눈·훅 아이·라인 아이 위치까지 해당 루어에 맞게 설정합니다. 단면 형태는 측정값이 아니라 루어 종류에 따른 추정값입니다: 둥근 펜슬·포퍼·톱워터는 타원, 라피도·전갱이·캡틴베이트 Type2·3은 약간 각지게(2.2, 전갱이·Type2·3은 배 쪽이 약간 넓게), 레가토는 플랫 펜슬(2.8), 립리스 미노우·저크베이트는 옆면이 평평하게(3.0), 바이브레이션은 더 평평하고 배가 넓게(3.5), 크랭크는 통통하고 배가 넓게(2.3). 웨이트는 타원일 때와 같은 총무게·부력 상태·정지 자세가 나오도록 맞췄습니다(서스펜딩인 저크베이트는 늘어난 부피만큼 12.8 → 14.0g). 화면은 루어 크기에 맞춰 자동으로 확대됩니다.
> 처음 열면 **농어 › MN001**(립리스 미노우)가 표시되며, **↺ 초기화**는 현재 선택한 프리셋 형상으로 되돌립니다.
> 프리셋을 불러온 뒤 형상이나 설정을 바꾸면 하단 상태바에 `(수정됨)`이 표시됩니다.

### 바디 형태
루어의 기본 치수를 제어합니다.

| 항목 | 설명 | 범위 |
|------|------|------|
| 측면 포인트 수 | 측면 윤곽의 컨트롤 포인트 개수 | 8~32 |
| 상면 포인트 수 | 상면 윤곽의 컨트롤 포인트 개수 | 8~32 |
| 곡선 부드러움 | 0 = 직선 연결, 1.00 = 자연스러운 곡선(기본, 최대). 점 간격에 맞춰 곡률을 조정하고 제어점 길이를 제한해, 어떤 값에서도 꺾이거나 고리가 생기지 않음 | 0~1.0 |
| 전체 길이 | 코끝~꼬리 길이 (mm) | 40~250 |
| 비율 유지 | 켜면 길이 변경 시 높이·폭·파츠·웨이트 지름이 같은 비율로, 웨이트·훅 무게가 부피에 비례해 함께 바뀜. 손을 떼면 루어가 화면을 벗어난 경우 자동 맞춤 | 끔 (라피도·레가토·캡틴베이트 펜슬은 켜짐) |
| 측면 높이 | 측면에서 본 세로 높이 (mm) | 8~80 |
| 상면 너비 | 상면에서 본 좌우 너비 (mm) | 6~60 |
| 단면 각짐 | 몸통을 가로로 자른 모양. 2 = 타원, 클수록 모서리가 둥근 사각에 가까워짐(같은 높이·폭에서 체적 최대 약 +23%, 지수 6 기준). 옆에 실제 높이:폭 비율의 단면 미리보기 | 2~6 (타원) |
| 단면 계란형 | 단면 위아래 비대칭. + = 배 쪽이 넓음, − = 등 쪽이 넓음. 부력중심 높이와 롤 안정성에 반영 | −0.4~0.4 (대칭) |

> 전체 길이 변경 시 측면과 상면이 동시에 스케일되며, 코끝 위치를 기준으로 조절됩니다.
> 측면·상면 포인트 수와 곡선 부드러움은 패널 아래 **고급** 항목을 펼치면 나옵니다.

### 립 (Lip)
- **립 표시** (기본: 꺼짐) — 활성화하면 코끝 아래에 립이 표시됩니다
- **립 길이**: 5~80mm
- **립 각도**: 0~80° (각도가 클수록 깊이 잠행)

### 파츠 (드래그로 위치 이동)
눈, 훅 아이, 라인 아이를 추가/삭제하고 드래그로 위치를 조정합니다.

| 파츠 | 설명 |
|------|------|
| 👁 눈 | +/− 버튼으로 추가/삭제, 드래그로 위치 이동 |
| 🪝 훅 아이 | 트레블 훅 연결 위치 |
| 🔗 라인 아이 | 라인(스냅) 연결 위치 |

- 파츠 선택 후 **Delete** 또는 **Backspace** 키로 삭제 가능 (PC)
- **Esc** 키로 선택 해제
- 눈 크기, 훅/아이 크기를 슬라이더로 조절

### 웨이트
내부 웨이트(납)를 넣고 무게·위치·크기를 조절합니다.

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 내부 웨이트 | 웨이트 목록(번호 탭으로 선택) · **＋ 추가**(선택한 웨이트를 복사해 15% 뒤에 배치) / **－ 삭제**. 아래 슬라이더는 선택한 웨이트를 조절 | 1개 |
| 무게 | 선택한 웨이트의 무게 (g, 0.5~100), 납(11.3 g/cm³)으로 계산 | 5 |
| 위치 | 코끝 기준 앞↔뒤 위치 (%). 측면 뷰의 회색 타원을 드래그해도 조절 | 50 |
| 지름 | 웨이트 지름 (mm, 1~30). 같은 무게에서 길이가 따라 바뀌고(옆에 표시), 높이 배치에 따라 무게중심 높이에 반영. 길이가 코끝·꼬리끝을 넘지 않는 범위로 제한(옆에 `가능 최소~최대` 표시) | 무게에 맞춘 1.5:1 슬러그 |

> **내부 웨이트**는 측면·상면 뷰에 회색 타원으로 표시됩니다. 여러 개를 넣을 수 있으며(최대 8개, 2개 이상이면 번호 표시), 측면 뷰에서 타원을 드래그하면 해당 웨이트가 선택되고 위치(5~95%)가 바뀝니다. 타원은 납 무게와 같은 부피로, 지름을 줄이면 길쭉한 슬러그, 키우면 둥근 볼 형태가 됩니다.
>
> 웨이트는 **코끝·꼬리끝을 넘지 않습니다** (벽 두께 0.8mm). 위치를 옮기거나 드래그해도 웨이트 모양(무게·지름)은 그대로이며, 코끝·꼬리끝에 닿는 지점에서 멈춥니다. **위아래·좌우는 외곽선 밖으로 나올 수 있고**, 나온 부분은 주황색으로 표시되며 웨이트 목록 아래에 알림이 뜹니다. 튀어나와도 무게는 루어 내부에 있는 것으로 계산합니다(웨이트 부피는 바디 배수량에 이미 포함, 그 자리의 바디 재질 무게만 뺌). 높이는 웨이트 전체 길이를 따라 바디 안에 들어가는 범위에서 가능한 한 배 쪽에 놓이고, 바디보다 굵어 안에 들어갈 수 없으면 윗면을 등 안쪽에 맞추고 **배 아래로** 튀어나옵니다. 지름이 너무 가늘어 길이가 코끝·꼬리끝을 넘게 되면 들어가는 지름으로 맞춰집니다.

### 소재·부속
바디 소재와 훅·코팅·내부 부속의 무게를 설정합니다.

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 소재 밀도 | 바디 전체의 평균(유효) 밀도 (g/cm³) | 0.50 |
| 훅+링 무게 | 훅 아이 1개당 트레블훅+스플릿링 무게 (g), 0~15 | 1.5 (라피도·레가토·캡틴베이트 펜슬 200mm 6.5) |
| 코팅·도장 무게 | 에폭시·도장 무게 (g, 0~20). 바디 표면에 고르게 입혀진 껍질로 계산(에폭시 1.15 g/cm³): 그 부피만큼 배수량도 늘고, 무게중심은 표면 쪽 | 0 |
| 와이어·래틀 등 내부 부속 | 관통 와이어·래틀 등 바디 안 부속 무게 (g, 0~30). 바디 중심축을 따라 고르게 분포, 바디 안이라 부피는 더하지 않고 그 자리의 바디 재질 무게를 뺌 | 0 |

> 소재 밀도 참고: 발사 0.15 / 오동나무 0.3 / 속이 빈 ABS 바디(유효 밀도) 0.5~0.7.
> 계산은 속이 꽉 찬 바디를 가정하므로, 중공 바디는 재질 밀도(ABS 1.05)가 아니라 바디 전체 평균 밀도를 입력하세요.

### 📊 액션 예측
맨 위의 **리트리브 속도**(1~5단계, 약 0.3 / 0.5 / 0.8 / 1.1 / 1.5 m/s, 기본: 보통)가 잠행 깊이·워블·저크 세기에 반영됩니다.

바디 형태와 물리 설정을 기반으로 자동 계산되는 9가지 예측 수치:

| 항목 | 설명 |
|------|------|
| 부력 상태 | 전체 무게 ÷ 배수량 기준 F(<0.95) / SF(<0.98) / SP(0.98~1.02) / SS(≤1.05) / S (**바닷물 기준**, 밀도 1.025 g/cm³) |
| 정지 자세 | 무게중심이 부력중심 바로 아래에 오는 기울기. 플로팅은 수면 흘수선까지 계산 |
| 예상 체적 | 화면의 곡선 외곽선에서 측면 높이 × 상면 너비 단면(단면 각짐·계란형 반영, 기본 타원)을 길이 방향으로 적분 (cm³) |
| 예상 무게 | 바디 + 웨이트 + 훅(훅 아이 수 × 훅+링 무게) + 립 + 코팅 + 내부 부속 (g). 웨이트는 바디 안에 박히므로 그 자리의 바디 재질 무게를 빼고, 부피는 이미 바디 배수량에 들어 있어 따로 더하지 않음 |
| 잠행 깊이 | 립 길이/각도와 속도(빠를수록 최대 깊이에 수렴), 정지 자세 반영. 다이빙 펜슬은 저크 시 잠수 깊이, 톱워터·포퍼는 수면, 싱킹은 침강 속도(cm/s). 침강·부상 속도는 정지 자세를 반영: 수평이면 옆면으로(상면 면적, Cd≈1), 기울수록 머리·꼬리부터(단면적, Cd≈0.3) 떨어져 더 빠름 |
| 루어 타입 | 형태·부력·자세로 자동 판정한 타입과 맞는 운용법 (아래 표) |
| 액션 특성 | 립·립리스 워블러는 워블 폭과 빈도(Hz, 속도 ÷ 바디 높이에 비례), 펜슬·톱워터는 롤링·다팅 / 도그워크 / 팝 등 |
| 롤링 경향 | 너비/높이 비율 기반 판정 + **롤 안정성**: 정지 자세에서의 횡방향 복원 높이 GM(mm) = 부력중심이 무게중심보다 높은 거리 + (뜰 때) 흘수면 2차 모멘트 ÷ 배수량. GM/바디 높이로 복원 강함·보통·약함, GM ≤ 0이면 ⚠ 옆으로 뒤집힘 경고. 액션 미리보기의 롤 폭도 GM이 작을수록 커짐 |
| 캐스팅 비거리 | 공기 저항을 넣은 비행 시뮬레이션 추정 거리(같은 태클 가정): 55 m 이상 장거리, 40 m 이상 중거리 |

> 모든 수치는 설계 비교용 근사치입니다. 부력·자세는 바닷물(1.025 g/cm³) 기준이며, 민물에서는 같은 루어가 약간 더 가라앉아 플로팅 루어의 꼬리 숙임이 커집니다. 실제 값은 내부 구조, 태클, 수온 등에 따라 달라집니다.

**▶ 액션 미리보기** 버튼으로 운용법별 2D 애니메이션 확인 가능:
- **운용법 선택**: 루어 타입에 맞는 운용법(롱 스위핑, 리트리브, 저크 & 포즈, 트위칭, 도그워크, 팝핑, 리프트 & 폴, 스톱 & 고)을 골라 움직임과 설명을 확인
- 측면은 수심 변화(눈금 m), 상면은 좌우 다팅·지그재그를 보여주며, 궤적이 뒤에 남습니다

- 실제 바디 형상이 반영됩니다
- **뷰**: 측면 / 상면 / 동시(위아래로 함께 표시). 캔버스를 탭하면 재생·일시정지
- **조작**: 재생 속도(0.25×~2×), 한 프레임씩 보기, 저크·트위치 세기와 포즈·정지 길이 슬라이더

- **수치**: 수심·속도·자세·워블 Hz 실시간 표시, 최근 6초 수심/속도/자세 그래프, 24초 시뮬 요약(최대 수심, 평균·최고 속도)
- **기준 비교**: 📌 기준 저장 후 디자인을 수정하고 다시 열면 저장한 궤적(주황 점선)·그래프와 수치 변화를 비교. 기준은 이 브라우저에 저장되어 새로고침해도 유지되며(저장 시각 표시), **기준 해제**로 지움
- **물리**: 속도는 로드 당김과 2차 항력(질량+부가질량)으로 결정되어 무거운 루어는 더 멀리 미끄러지고, 자세는 무게중심–부력중심 거리에서 나온 감쇠 스프링으로 복원 진동하며, 워블 주기는 실제 속도를 따라 멈추면 잦아듭니다

### 🎯 실측 보정
잠행 깊이·침강 속도·워블·비거리는 경험식이라 실물과 다를 수 있습니다. 실물 루어를 재서 보정할 수 있습니다.

1. 실물과 같은 디자인(또는 프리셋)을 불러온 뒤 **🎯 실측 보정** 패널을 엽니다.
2. 잰 값만 입력합니다(빈칸은 건너뜀). 입력하는 대로 예측값 아래에 차이가 표시됩니다(초록 = 5% 이내).
3. **측정값 저장**을 누르면 실측 ÷ 예측 비율이 기록되고, 저장된 비율들의 평균(기하평균)이 모든 디자인의 예측에 곱해집니다. 보정된 값에는 `· 보정`이 붙습니다.

| 입력 | 보정 대상 | 측정 방법 예 |
|---|---|---|
| 침강·부상 속도 (cm/s) | 침강·부상 속도 | 깊이를 아는 수조·수심에서 초시계로 측정 (서스펜딩은 해당 없음) |
| 잠행 깊이 (m) | 립 루어 잠행 깊이 (현재 리트리브 속도 기준) | 수심을 아는 곳에서 바닥 닿는 지점, 또는 깊이 측정용 라인 |
| 저크 잠수 깊이 (m) | 다이빙 펜슬의 저크 잠수 깊이 | 맑은 물에서 눈으로 / 수중 촬영 |
| 워블 (Hz) | 워블 주기 (립 루어·립리스 미노우·바이브) | 슬로 모션 촬영에서 1초당 좌우 왕복 횟수 |
| 비거리 (m) | 캐스팅 비거리 (평소 태클 기준) | 여러 번 던진 평균 |
| 무게 (g) | 보정 계수에는 쓰지 않음 | 저울. **밀도로 무게 맞추기**를 누르면 예측 무게가 실측과 같아지도록 이 디자인의 소재 밀도를 조정 |
| 정지 자세 (°) | 보정 계수에는 쓰지 않음 | 물에 띄워 각도 측정. 차이가 크면 웨이트·부속 위치가 실물과 다른 것 |

> 무게·정지 자세는 입력값(밀도, 웨이트)에서 계산되는 물리량이라, 차이는 모델이 아니라 그 디자인의 입력값 문제입니다. 그래서 비교만 하고 공통 보정은 하지 않습니다.
> 측정 기록은 이 브라우저에 저장되며, 기록별로 삭제하거나 **보정 적용**을 꺼서 모델 그대로의 예측과 비교할 수 있습니다.

- 자동 동기화: 포인트 추가/삭제/리샘플 시에도 양쪽 길이를 자동으로 맞춤

## 실제 크기 인쇄

상단의 **🖨 인쇄** 버튼을 누르면 측면 뷰(눈·훅 아이·립·웨이트 포함)와 상면 뷰가 1mm = 1mm로 그려진 인쇄 화면이 열립니다.

- 인쇄 대화상자에서 배율을 **100% (기본값 / 실제 크기)** 로 두고, "페이지에 맞춤"은 끄세요
- 종이에 함께 인쇄되는 **50mm 눈금자**를 자로 재서 프린터 배율을 확인할 수 있습니다
- 편집 화면처럼 1mm / 1cm 눈금이 함께 인쇄됩니다 (코끝 기준, 위쪽에 cm 숫자). 루어 안쪽에도 눈금이 보이도록 몸통은 채우지 않습니다
- 측면 그림의 몸통 안에 **디자인 코드**가 함께 인쇄됩니다: `프리셋 코드/부력/L길이/W무게/B폭/H높이` (예: `MN001/F/L125/W16/B14/H19` = MN001 기반, 플로팅, 길이 125mm, 무게 16g, 폭 14mm, 높이 19mm). 부력은 F / SF / SP / SS / S, 길이·폭·높이는 mm, 무게는 g이며 모두 반올림한 정수. 글자는 최대 3mm로, 몸통 안쪽에서 눈을 피해 들어가는 가장 큰 크기로 가운데 가까이 놓이며, 너무 작은 몸통이면 생략됩니다. 아래 설명줄에도 같은 코드가 표시됩니다(프리셋을 수정했으면 `(수정됨)`)
- A4 기준이며 루어가 190mm보다 길면 자동으로 가로 방향이 됩니다 (길이 250mm까지 한 장에 들어감). 긴 립 등으로 A4보다 커지면 알림과 함께 A3로 설정됩니다

## SVG 내보내기

상단 **⬇ SVG** 버튼을 클릭하면 현재 루어의 측면/상면 SVG 코드가 생성됩니다.
- 하나의 SVG 파일에 측면(위)과 상면(아래)이 각각 그룹(`side-view`, `top-view`)으로 출력
- 측면에는 립(활성 시)과 눈·훅 아이·라인 아이 파츠도 포함
- 내부 웨이트 위치를 점선 타원(`class="weight"`)으로 측면·상면에 표시
- 측면 몸통 안에 인쇄와 같은 디자인 코드(`class="design-code"`) 표시
- 클립보드 복사 또는 텍스트 선택하여 사용
- 벡터 그래픽이므로 Illustrator, Inkscape 등에서 추가 편집 가능

## 설계 팁

### 부력 조절
- **플로팅**: 가벼운 소재(발사·오동) 또는 중공 바디 + 적은 웨이트 → 정지 시 떠오름
- **서스펜딩**: 웨이트를 조절해 무게 ÷ 배수량을 0.98~1.02로 맞춤 → 수중에서 멈춤
- **싱킹**: 무게가 배수량을 넘김 → 정지 시 가라앉음 (립 없을 때 침강 속도 표시)
- 훅 아이를 추가하면 훅 무게가 더해지므로 부력이 줄어듭니다

### 워블 특성 (립·립리스 워블러)
- **높이/길이 비율이 클수록** (팻 바디) → 와이드 워블
- **높이/길이 비율이 작을수록** (슬림 바디) → 타이트 / 슈퍼 타이트 워블
- 속도가 빠를수록, 바디 높이가 낮을수록 워블 빈도(Hz)가 높아집니다

### 잠행 깊이
- **립이 길고 각도가 작을수록**(수평에 가까울수록) → 깊이 잠행
- **리트리브 속도가 빠를수록** → 더 깊이 들어가지만 최대 깊이에 수렴
- **머리 숙인 정지 자세**(웨이트 앞쪽) → 립이 빨리 물어 약간 더 깊이

### 캐스팅 비거리
- **무겁고 단면적이 작을수록** (슬림 + 무거움) → 장거리 캐스팅
- **단면적이 클수록** (팻 바디) → 공기 저항으로 비거리 감소
- **무게중심이 뒤쪽일수록** → 꼬리부터 안정적으로 날아가 비거리 증가
