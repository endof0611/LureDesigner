# 🐟 미노우 루어 디자이너 - 사용 설명서

## 개요

미노우 루어 디자이너는 웹 브라우저에서 실행되는 루어 설계 도구입니다. 측면(Side)과 상면(Top) 두 시점에서 루어 외형을 편집하고, 부력·정지 자세·잠행 깊이 같은 물리 예측과 운용법별 액션 미리보기까지 확인할 수 있습니다. 별도 설치 없이 HTML 파일 하나로 PC, 태블릿, 스마트폰에서 모두 사용할 수 있습니다.

**주요 기능**
- 측면·상면 외곽선 편집, 단면 형태(각짐·계란형) 설정
- 내부 웨이트 여러 개(무게·위치·지름), 눈·훅 아이·라인 아이, 립
- 바닷물 기준 부력, 정지 자세, 롤 안정성(GM), 잠행 깊이, 침강·부상 속도, 비거리 예측
- 디자인에 맞는 **추천 운용법**과 운용법별 **액션 미리보기**(롱 스위핑, 저크 등)
- 실물 측정값으로 예측을 맞추는 **실측 보정**
- 실제 크기(1:1) 인쇄와 SVG 내보내기, 루어에 들어가는 **디자인 코드**

---

## 빠른 시작

1. 왼쪽 **루어 프리셋**에서 비슷한 루어를 고릅니다 (예: 빅게임 › BG003).
2. 캔버스의 점을 끌거나 **바디 형태**·**웨이트**·**소재·부속** 값을 바꿔 다듬습니다.
3. **📊 액션 예측**에서 부력·자세·추천 운용법을 확인하고 **⭐ 추천대로 미리보기**로 움직임을 봅니다.
4. 상단 **🖨 인쇄**로 실제 크기 도면을 출력하거나 **⬇ SVG**로 내보냅니다.

### 캔버스 영역
화면 중앙에 측면 뷰(위)와 상면 뷰(아래)가 나란히 배치됩니다.

- **흰색 배경**에 **검정 외곽선**(두께 1.5)으로 루어를 표시
- **그리드**: 보조선 1mm, 주선 1cm, 코끝 기준 정렬, 항상 표시. 루어 안쪽에도 눈금이 비쳐 보입니다
- **기준선**: 세로선은 코끝 위치, 가로선은 중심축
- 측면과 상면의 **코끝 위치는 항상 정렬**되어 길이 비교가 쉽습니다
- 각 뷰 **오른쪽 위**에 현재 치수를 실시간 표시 (측면: 길이·최대 높이, 상면: 길이·최대 폭, 0.1mm 단위)
- 길이·높이·폭은 컨트롤 포인트가 아니라 **화면에 그려진 곡선 외곽선** 기준입니다 (꼬리 끝면은 곡선이 포인트보다 1~2mm 둥글게 나감)
- 하단 상태바에 현재 프리셋 코드와 포인트 수가 표시되며, 프리셋을 수정하면 `(수정됨)`이 붙습니다

## 사이드바 메뉴

루어 프리셋은 펼쳐진 상태로, 나머지는 접힌 상태로 시작하며 제목을 누르면 펼치거나 접힙니다. 작업 순서대로 배치되어 있습니다.

**루어 프리셋 → 바디 형태 → 립 → 파츠 → 웨이트 → 소재·부속 → 화면 설정 → 📊 액션 예측 → 🎯 실측 보정**

### 루어 프리셋
루어 타입(**빅게임 / 농어 / 기타**)을 고른 뒤 그 안의 프리셋을 선택하면 해당 형상이 표시됩니다. 불러온 형상은 일반 편집과 똑같이 자유롭게 수정할 수 있습니다.

프리셋은 코드로 표시됩니다: 빅게임 **BG**, 농어 **MN**, 기타 **ET** + 목록 순서 번호(001~). 코드 옆에 설명이 나옵니다. 처음 열면 **MN001**이 표시됩니다.

### 바디 형태
| 항목 | 설명 | 범위 |
|------|------|------|
| 전체 길이 | 코끝~꼬리 길이 (mm). 측면·상면이 코끝 기준으로 함께 바뀜. 최대값은 A4에 1:1로 인쇄할 수 있는 길이 | 40~266 |
| 비율 유지 | 켜면 길이를 바꿀 때 높이·폭·파츠·웨이트 지름이 같은 비율로, 웨이트·훅·부속 무게는 부피(길이³)에, 코팅은 표면적(길이²)에 비례해 함께 바뀜. 손을 떼면 루어가 화면을 벗어난 경우 자동 맞춤 | 끔 (BG003~BG007은 켜짐) |
| 측면 높이 | 측면에서 본 세로 높이 (mm) | 8~80 |
| 상면 너비 | 상면에서 본 좌우 너비 (mm) | 6~60 |
| 단면 각짐 | 몸통을 가로로 자른 모양. 2 = 타원, 클수록 모서리가 둥근 사각에 가까워짐 (같은 높이·폭에서 체적 최대 약 +23%). 옆에 실제 높이:폭 비율의 단면 미리보기 | 2~6 (타원) |
| 단면 계란형 | 단면 위아래 비대칭. + = 배 쪽이 넓음, − = 등 쪽이 넓음. 부력중심 높이와 롤 안정성에 반영 | −0.4~0.4 (대칭) |

**고급** 항목(패널 아래를 펼침):

| 항목 | 설명 | 범위 |
|------|------|------|
| 측면·상면 포인트 수 | 윤곽의 컨트롤 포인트 개수 | 8~32 |
| 곡선 부드러움 | 0 = 직선 연결, 1.00 = 자연스러운 곡선(기본). 어떤 값에서도 꺾이거나 고리가 생기지 않음 | 0~1.0 |

### 립 (Lip)
- **립 표시** (기본: 꺼짐): 켜면 코끝 아래에 립이 표시됩니다
- **립 길이**: 5~80mm (길수록 깊이 잠행)
- **립 각도**: 0~80° (작을수록, 즉 수평에 가까울수록 깊이 잠행. 클수록 얕고 워블이 강함)

| 파츠 | 설명 |
|------|------|
| 👁 눈 | +/− 버튼으로 추가/삭제, 드래그로 위치 이동 |

| 🔗 라인 아이 | 라인(스냅) 연결 위치 (등 쪽이면 바이브레이션으로 판정) |

### 웨이트
내부 웨이트(납, 11.3 g/cm³)를 넣고 무게·위치·크기를 조절합니다. 측면·상면 뷰에 회색 타원으로 표시됩니다.

| 항목 | 설명 | 범위 (기본값) |
|------|------|--------|
| 웨이트 목록 | 번호 탭으로 선택, **＋ 추가**(선택한 웨이트를 같은 모양으로 복사해 약 15% 뒤에 배치) / **－ 삭제**. 최대 8개, 2개 이상이면 타원에 번호 표시 | (1개) |
| 무게 | 선택한 웨이트의 무게 (g) | 0.5~100 |
| 위치 | 코끝 기준 앞↔뒤 위치 (%). 측면 뷰에서 타원을 드래그해도 조절 | 5~95 |
| 지름 | 웨이트 지름 (mm). 같은 무게에서 지름을 줄이면 길쭉한 슬러그, 키우면 둥근 볼. 옆에 길이와 `가능 최소~최대` 표시 | 1~30 (무게에 맞춘 1.5:1 슬러그) |

- **코끝·꼬리끝은 넘지 않습니다** (벽 두께 0.8mm). 옮기거나 드래그해도 무게·지름은 그대로이고, 끝에 닿는 지점에서 멈춥니다. 지름이 너무 가늘어 길이가 끝을 넘으면 들어가는 지름으로 맞춰집니다.
- **위아래·좌우는 외곽선 밖으로 나올 수 있습니다.** 나온 부분은 주황색으로 표시되고 목록 아래에 알림이 뜹니다. 튀어나와도 무게는 루어 내부로 계산합니다.
- 높이는 웨이트 전체 길이를 따라 바디 안에 들어가는 범위에서 가능한 한 배 쪽에 놓이고, 바디보다 굵으면 윗면을 등 안쪽에 맞추고 배 아래로 튀어나옵니다.
- 바디를 줄여 웨이트가 끝을 넘게 되면 지름(필요하면 무게)이 자동 조정되고 ⚠ 알림이 표시됩니다.

### 소재·부속
| 항목 | 설명 | 기본값 |
|------|------|--------|
| 소재 밀도 | 바디 전체의 평균(유효) 밀도 (g/cm³, 0.01 단위) | 0.50 |
| 훅+링 무게 | 훅 아이 1개당 트레블훅+스플릿링 무게 (g, 0~15) | 1.5 (BG003~BG007 200mm는 6.5) |
| 코팅·도장 무게 | 에폭시·도장 무게 (g, 0~20). 표면에 고르게 입힌 껍질로 계산 (에폭시 1.15 g/cm³): 그 부피만큼 배수량도 늘고 무게중심은 표면 쪽 | 0 |
| 와이어·래틀 등 내부 부속 | 관통 와이어·래틀 등 (g, 0~30). 바디 중심축을 따라 고르게 분포, 바디 안이라 부피는 더하지 않음 | 0 |

> 소재 밀도 참고: 발사 0.15 / 오동나무 0.3 / 속이 빈 ABS 바디(유효 밀도) 0.5~0.7.
> 계산은 속이 꽉 찬 바디를 가정하므로, 중공 바디는 재질 밀도(ABS 1.05)가 아니라 바디 전체 평균 밀도를 입력하세요. 실물 무게를 알면 [실측 보정](#-실측-보정)의 **밀도로 무게 맞추기**로 맞출 수 있습니다.

### 📊 액션 예측
맨 위의 **리트리브 속도**(1~5단계, 약 0.3 / 0.5 / 0.8 / 1.1 / 1.5 m/s, 기본: 보통)가 잠행 깊이·워블·저크 세기에 반영됩니다. 아래 값은 형상과 설정이 바뀔 때마다 자동으로 다시 계산됩니다.

| 항목 | 설명 |
|------|------|
| 부력 상태 | 전체 무게 ÷ 배수량: F(<0.95) / SF(<0.98) / SP(0.98~1.02) / SS(≤1.05) / S. **바닷물 기준** (1.025 g/cm³) |
| 정지 자세 | 무게중심이 부력중심 바로 아래에 오는 기울기 (머리 숙임 / 꼬리 숙임 / 수평). 플로팅은 흘수선까지 계산 |
| 예상 체적 | 외곽선과 단면 형태로 적분한 바디 체적 (cm³) |
| 예상 무게 | 바디 + 웨이트 + 훅 + 립 + 코팅 + 내부 부속 (g) |
| 잠행 깊이 | 립 루어: 립 길이·각도·속도·자세로 계산한 깊이. 다이빙 펜슬: 저크 시 잠수 깊이. 톱워터·포퍼: 수면. 싱킹: 침강 속도 |
| 루어 타입 | 형상·부력·자세로 자동 판정한 타입과 운용법 ([루어 타입과 운용법](#루어-타입과-운용법)) |
| 액션 특성 | 립·립리스 워블러는 워블 폭과 빈도(Hz), 펜슬·톱워터는 롤링·다팅 / 도그워크 / 팝 등 |
| 롤링 경향 | 너비/높이 비율 + **롤 안정성**(GM): 복원 강함·보통·약함, GM ≤ 0이면 ⚠ 옆으로 뒤집힘 경고 |
| 캐스팅 비거리 | 공기 저항을 넣은 비행 시뮬레이션(같은 태클 가정): 55 m 이상 장거리, 40 m 이상 중거리 |

실측 보정이 적용된 값에는 `· 보정`이 붙습니다. 그 아래에는 정지 자세·웨이트 위치·바디 비율 등에 대한 한 줄 코멘트가 표시됩니다.

#### ⭐ 추천 운용법
패널 아래에 이 디자인에 맞는 **운용법·리트리브 속도·당기는 세기·포즈 길이**와 그 이유가 표시됩니다. **⭐ 추천대로 미리보기**를 누르면 그 설정으로 액션 미리보기가 재생되고, 미리보기 안의 **⭐ 추천 설정** 버튼으로 언제든 되돌릴 수 있습니다.

| 근거 (계산값) | 추천 예 |
|---|---|
| 정지 자세 | 다이빙 펜슬이 꼬리를 12° 이상 숙이면 롱 스위핑, 거의 수평이면 짧은 저크로 수면 아래 슬라이드 |
| 무게 | 70g 이상 펜슬은 빠르게 당기기 |
| 롤 복원 높이 GM (바디 높이 대비) | 크면 세게(×1.3), 작으면 약하게(×0.8) 당기기 |
| 부상·침강 속도 | 빨리 뜨면 포즈 짧게. 빨리 가라앉는 싱킹 펜슬·바이브는 리프트 & 폴 |
| 부력·립 | 서스펜딩은 저크·트위칭 후 길게 포즈, 긴 립 크랭크는 빠르게, 포퍼는 팝 후 쉬기 |

> 추천은 리트리브 속도에 따라 바뀌는 값을 쓰지 않으므로 적용해도 추천이 바뀌지 않습니다. 계산값에서 나온 경향이며, 실제 조황의 정답은 아닙니다.

#### ▶ 액션 미리보기
운용법별 움직임을 2D 애니메이션으로 보여줍니다. 실제 바디 형상이 반영되고, 루어는 항상 머리 방향(로드 쪽)으로 진행합니다.

- **운용법 선택**: 루어 타입에 맞는 운용법을 골라 움직임과 설명을 확인 (첫 번째가 기본)
- **뷰**: 측면(수심, 눈금 m) / 상면(좌우 다팅·지그재그) / 동시. 캔버스를 탭하면 재생·일시정지
- **조작**: 재생 속도(0.25×~2×), ⏭ 한 프레임씩 보기, 저크·트위치 세기와 포즈·정지 길이 슬라이더
- **시각 효과**: 궤적, 수심 그라데이션과 빛줄기, 잔상, 잠행 중 기포, 수면 파문, 바닥(리프트 & 폴), ⊕ 무게중심·부력중심
- **수치**: 수심·속도·자세·워블 Hz 실시간 표시, 최근 6초 그래프, 24초 시뮬 요약(최대 수심, 평균·최고 속도)
- **기준 비교**: 📌 기준 저장 후 디자인을 수정하고 다시 열면 저장한 궤적(주황 점선)·그래프·수치 변화를 비교. 기준은 브라우저에 저장되어 새로고침해도 유지되며 **기준 해제**로 지움

> 액션 미리보기는 형태·부력·무게중심에서 나오는 경향을 보여주는 운동 스케치이며, 유체 시뮬레이션이 아닙니다.

### 🎯 실측 보정
잠행 깊이·침강 속도·워블·비거리는 경험식이라 실물과 다를 수 있습니다. 실물 루어를 재서 보정할 수 있습니다.

1. 실물과 같은 디자인(또는 프리셋)을 불러온 뒤 **🎯 실측 보정** 패널을 엽니다.
2. 잰 값만 입력합니다(빈칸은 건너뜀). 입력하는 대로 예측값 아래에 차이가 표시됩니다(초록 = 5% 이내).
3. **측정값 저장**을 누르면 실측 ÷ 예측 비율이 기록되고, 저장된 비율들의 평균(기하평균)이 **모든 디자인**의 예측에 곱해집니다.

| 입력 | 보정 대상 | 측정 방법 예 |
|---|---|---|
| 침강·부상 속도 (cm/s) | 침강·부상 속도 | 깊이를 아는 수조·수심에서 초시계로 측정 (서스펜딩은 해당 없음) |
| 잠행 깊이 (m) | 립 루어 잠행 깊이 (현재 리트리브 속도 기준) | 수심을 아는 곳에서 바닥 닿는 지점, 또는 깊이 측정용 라인 |
| 저크 잠수 깊이 (m) | 다이빙 펜슬의 저크·롱 스위핑 잠수 깊이 | 맑은 물에서 눈으로 / 수중 촬영 |
| 워블 (Hz) | 워블 주기 (립 루어·립리스 미노우·바이브) | 슬로 모션 촬영에서 1초당 좌우 왕복 횟수 |
| 비거리 (m) | 캐스팅 비거리 (평소 태클 기준) | 여러 번 던진 평균 |
| 무게 (g) | 보정 계수에는 쓰지 않음 | 저울. **밀도로 무게 맞추기**를 누르면 예측 무게가 실측과 같아지도록 이 디자인의 소재 밀도를 조정 |
| 정지 자세 (°) | 보정 계수에는 쓰지 않음 | 물에 띄워 각도 측정. 차이가 크면 웨이트·부속 위치가 실물과 다른 것 |

> 측정 기록은 이 브라우저에 저장되며, 기록별로 삭제하거나 **보정 적용**을 꺼서 모델 그대로의 예측과 비교할 수 있습니다.

`프리셋 코드/부력/L길이/W무게/B폭/H높이` 예: `MN001/F/L125/W16/B14/H19`

|---|---|
| MN001 | 기반 프리셋 코드 |
| F | 부력 상태 (F / SF / SP / SS / S) |

| W16 | 무게 16g |
| B14 | 폭 14mm |
| H19 | 높이 19mm |

- 숫자는 모두 반올림한 정수입니다
- 글자는 최대 3mm로, 몸통 안쪽에서 눈을 피해 들어가는 가장 큰 크기로 가운데 가까이 놓이며, 너무 작은 몸통이면 그림에서는 생략됩니다

### 실제 크기 인쇄
상단 **🖨 인쇄**를 누르면 측면 뷰(눈·훅 아이·립·웨이트 포함)와 상면 뷰가 1mm = 1mm로 그려진 인쇄 화면이 열립니다.

- 인쇄 대화상자에서 배율을 **100% (기본값 / 실제 크기)** 로 두고 "페이지에 맞춤"은 끄세요
- 함께 인쇄되는 **50mm 눈금자**를 자로 재서 프린터 배율을 확인할 수 있습니다
- 1mm / 1cm 눈금이 함께 인쇄됩니다 (코끝 기준, 위쪽에 cm 숫자). 눈금이 보이도록 몸통은 채우지 않습니다
- 몸통 안에 디자인 코드, 하단 설명줄에 `디자인 코드 · 실제 크기 (1:1)` (프리셋을 수정했으면 `(수정됨)`)
- 용지 여백은 5mm, 그림 좌우 여백은 2mm입니다. 대부분의 프린터가 가장자리 3~5mm를 인쇄하지 못하므로 그보다 줄이지 않았습니다
- 용지는 그림과 설명줄이 들어가는 크기로 자동 설정됩니다: A4 세로 → A4 가로 → A3 (A4에 들어가지 않으면 알림)
- 전체 길이 최대값(266mm)은 모든 프리셋이 A4 가로에 1:1로 들어가는 길이입니다. 립을 길게 하는 등 그보다 커지면 A3로 넘어갑니다

## 설계 팁

### 부력 조절
- **플로팅**: 가벼운 소재(발사·오동) 또는 중공 바디 + 적은 웨이트 → 정지 시 떠오름
- **서스펜딩**: 웨이트를 조절해 무게 ÷ 배수량을 0.98~1.02로 맞춤 → 수중에서 멈춤
- **싱킹**: 무게가 배수량을 넘김 → 정지 시 가라앉음
- 훅 아이, 코팅, 내부 부속을 더하면 무게가 늘어 부력이 줄어듭니다
- 각진 단면은 같은 외곽선이라도 체적이 커서 더 잘 뜹니다

### 정지 자세와 롤 안정성
- 웨이트를 **뒤쪽**에 두면 꼬리 숙임 → 다이빙 펜슬·포퍼형, 비행이 안정되어 비거리↑
- 웨이트를 **앞쪽**에 두면 머리 숙임 → 립이 빨리 물어 잠행이 빨라짐
- 웨이트를 **낮게**(배 쪽) 둘수록 롤 복원(GM)이 커져 덜 구르고, GM이 작으면 롤링이 커집니다

### 워블 특성 (립·립리스 워블러)
- **높이/길이 비율이 클수록**(팻 바디) → 와이드 워블, **작을수록**(슬림) → 타이트 워블
- 속도가 빠를수록, 바디 높이가 낮을수록 워블 빈도(Hz)가 높아집니다

### 잠행 깊이
- **립이 길고 각도가 작을수록**(수평에 가까울수록) → 깊이 잠행
- **리트리브 속도가 빠를수록** → 더 깊이 들어가지만 최대 깊이에 수렴
- **머리 숙인 정지 자세** → 립이 빨리 물어 약간 더 깊이
- 다이빙 펜슬은 **꼬리를 많이 숙일수록, 길수록** 깊게 잠수하고, 롱 스위핑이 저크보다 깊습니다

### 캐스팅 비거리
- **무겁고 단면적이 작을수록** (슬림 + 무거움) → 장거리
- **단면적이 클수록** (팻 바디) → 공기 저항으로 비거리 감소
- **무게중심이 뒤쪽일수록** → 꼬리부터 안정적으로 날아가 비거리 증가

## 계산 모델

모든 수치는 설계 비교용 근사치입니다. 실제 값은 내부 구조, 태클, 수온 등에 따라 달라집니다.

| 항목 | 방법 |
|---|---|
| 체적·무게중심 | 곡선 외곽선을 길이 방향 96개 단면으로 나누고, 단면(측면 높이 × 상면 폭, 단면 형태 반영)을 적분. 웨이트·훅·립·코팅·부속은 각 위치의 질량으로 더함 |
| 부력 | 바닷물(1.025 g/cm³) 기준. 민물에서는 같은 루어가 약간 더 가라앉아 플로팅 루어의 꼬리 숙임이 커짐 |
| 정지 자세 | 각도마다 흘수선(잠긴 부분이 무게를 받치는 수면 높이)을 풀어 부력중심을 구하고, 무게중심과 수직으로 맞는 각도를 찾음 |
| 롤 안정성 GM | 부력중심이 무게중심보다 높은 거리 + (뜰 때) 흘수면 2차 모멘트 ÷ 배수량 |
| 침강·부상 속도 | 순 무게(또는 부력)와 항력의 균형. 수평이면 상면 면적(Cd≈1), 기울수록 단면적(Cd≈0.3) |
| 잠행 깊이·워블·다이빙 펜슬 잠수 | 경험식 (립 길이·각도·속도, 꼬리 숙임·길이·부력 여유). 실측 보정으로 맞출 수 있음 |
| 비거리 | 같은 태클을 가정한 공기 저항 포함 비행 시뮬레이션 |
| 액션 미리보기 | 로드 당김과 2차 항력(질량+부가질량)으로 속도, 무게중심–부력중심 거리로 자세 복원 진동, 상면 면적 항력으로 수직 감속. 표시된 잠수 깊이를 넘어 미끄러지지 않도록 하강 속도를 조절 |

## 프리셋 상세

- **BG003~BG007**은 200mm 기준 형상이며 **비율 유지**가 켜진 상태로 불러옵니다. 길이를 160·230mm 등으로 바꾸면 같은 루어의 다른 사이즈처럼 동작합니다.
- 외곽선은 24~30개 포인트로 표현합니다. 측정 지점이 적은 프리셋은 설계값을 그대로 지나는 단조 3차 보간으로 지점을 늘려 선이 자연스럽게 이어집니다.
- **BG003 (라피도)**: 실물 F230 측면 사진에서 관통 와이어 축(라인 아이→꼬리 아이) 기준으로 외곽선을 추출. 상면은 머리가 넓고 뭉툭하며 폭이 거의 일정하다가 꼬리 쪽에서만 좁아지게(최대 폭 27~29mm @230mm). 230mm에서 몸통 100g(훅 제외), 훅 아이당 10g(권장 싱글 8~11g + DAEN #9 링). 정지 자세는 공개 자료가 없어 일반적인 다이빙 펜슬(꼬리 숙임 약 35°)로 가정.
- **BG004 (레가토)**: 실물 F190 사진(측면·상면)에서 외곽선 추출. 등은 끝까지 높고 배가 꼬리 쪽으로 올라가 꼬리가 라인 아이보다 위에 있음. F190 60g을 200mm로 환산한 70g에서 플로팅·수평 정지(물에 띄운 사진과 일치).
- **BG005~BG007 (캡틴베이트 Type1~3)**: 측면·상면 사진(양쪽 면 평균)에서 관통 와이어 축 기준으로 외곽선 추출. 무게·자세 자료가 없어 200mm에서 약 70g·89g·92g, 꼬리 숙임 약 20°의 일반적인 플로팅 다이빙 펜슬로 가정.
- **단면 형태**는 측정값이 아니라 루어 종류에 따른 추정값입니다: 둥근 펜슬·포퍼·톱워터는 타원, BG001·BG003·BG006·BG007은 약간 각지게(2.2, BG001·BG006·BG007은 배 쪽이 약간 넓게), BG004는 플랫 펜슬(2.8), MN001·ET003은 옆면이 평평하게(3.0), MN002는 더 평평하고 배가 넓게(3.5), ET001은 통통하고 배가 넓게(2.3).
- 웨이트는 바닷물 기준, 단면 형태를 넣었을 때도 위 무게·부력 상태·정지 자세가 나오도록 맞췄습니다 (서스펜딩인 ET003은 늘어난 부피만큼 14.0g).

## 기술 사양

| 항목 | 내용 |
|------|------|
| 파일 형식 | 단일 HTML 파일 (`index.html`, 약 2,850줄) |
| 프레임워크 | 없음 (순수 HTML/CSS/JavaScript) |
| 그래픽 | SVG (편집 뷰·인쇄·내보내기) + Canvas 2D (액션 미리보기) |
| 좌표계 | mm 단위 (그리드: 1mm 보조선, 1cm 주선) |
| 외곽선 구조 | 코끝에서 시작해 위쪽 윤곽 → 꼬리 → 아래쪽 윤곽 → 코끝으로 닫히는 폐곡선 (포인트 8~32개, 프리셋 24~30개) |
| 곡선 보간 | Catmull-Rom 계열 접선 → 3차 베지어 (부드러움 조절, 꺾임·고리 방지) |
| 입력 지원 | Pointer Events API (마우스, 터치, Apple Pencil, 핀치 줌) |
| 반응형 | 768px 이하 모바일, 769~1024px 태블릿, 1025px 이상 데스크톱 |
| 저장 | 브라우저 localStorage: 액션 미리보기 기준, 실측 보정 기록 |
| 히스토리 | 최대 40단계 실행취소 |
