# 🐟 미노우 루어 디자이너 - 사용 설명서

## 개요

미노우 루어 디자이너는 웹 브라우저에서 실행되는 미노우 루어 설계 도구입니다. 측면(Side)과 상면(Top) 두 가지 시점에서 루어의 외형을 편집하고, 물리 기반의 액션 예측까지 확인할 수 있습니다. 별도 설치 없이 HTML 파일 하나로 PC, 태블릿, 스마트폰에서 모두 사용 가능합니다.

---

## 화면 구성

### 상단 헤더
| 버튼 | 기능 |
|------|------|
| ☰ | 사이드바 열기/닫기 (모바일) |
| 📐 크기맞춤 | 측면/상면 길이를 기준 뷰에 맞춰 동기화 |
| ↺ 초기화 | 선택한 프리셋 형상으로 되돌림 |
| ⌫ 실행취소 | 이전 상태로 복원 (최대 40단계, 프리셋 전환·대칭·립·웨이트 설정 포함) |
| ⬇ SVG | 현재 루어 형상을 SVG 코드로 내보내기 |

### 캔버스 영역
화면 중앙에 측면 뷰(위)와 상면 뷰(아래)가 나란히 배치됩니다.

- **흰색 배경**에 **검정 외곽선**으로 루어가 표시됩니다
- **그리드**: 보조선 1mm, 주선 1cm 간격 (코끝 기준 정렬)
- **기준선**: 세로선은 코끝 위치, 가로선은 중심축
- 측면과 상면의 **코끝(앞부분) 위치는 항상 정렬**되어 길이 비교가 용이합니다

### 캔버스 툴바
| 도구 | 아이콘 | 설명 |
|------|--------|------|
| 이동 | ✋ | 포인트 드래그로 형상 편집 (기본) |
| 추가 | ＋ | 클릭 위치에 새 컨트롤 포인트 추가 |
| 삭제 | ✕ | 클릭한 포인트 제거 |
| 확대 | 🔍+ | 줌 인 |
| 축소 | 🔍− | 줌 아웃 |
| 리셋 | ⊞ | 패닝 초기화 + 루어 크기에 맞춰 자동 확대 |

## 사이드바 메뉴 (접기/펼치기)

루어 프리셋 메뉴는 펼쳐진 상태로, 나머지 메뉴는 접힌 상태로 시작하며 제목을 클릭하면 펼치거나 접을 수 있습니다.

### 루어 프리셋 (최상단)
루어 타입(**빅게임 / 농어 / 기타**)을 고른 뒤, 그 안의 대표 형상 3가지 중 하나를 선택하면 해당 형상이 화면에 표시됩니다. 표시된 형상은 일반 편집과 똑같이 포인트·슬라이더로 자유롭게 수정할 수 있습니다.

| 타입 | 프리셋 | 형태 | 기본 동작 |
|------|--------|------|-----------|
| 빅게임 | 전갱이 | 다이빙 펜슬 180mm, 깊은 체고 | 플로팅, 꼬리 숙인 자세 |
| 빅게임 | 날치 | 롱 펜슬 200mm, 슬림 | 플로팅, 꼬리 숙인 자세 |
| 빅게임 | 포퍼 | 컵 페이스 160mm | 플로팅 |
| 농어 | 플로팅 미노우 | 립 미노우 125mm | 플로팅, 수평 자세 |
| 농어 | 바이브레이션 | 립리스 75mm, 등 쪽 라인 아이 | 싱킹 |
| 농어 | 싱킹 펜슬 | 슬림 100mm | 싱킹, 수평 자세 |
| 기타 | 크랭크베이트 | 배스용 팻 바디 60mm, 립 | 플로팅 |
| 기타 | 톱워터 펜슬 | 워킹 베이트 110mm, 후방 웨이트 | 플로팅, 꼬리 숙인 자세 |
| 기타 | 저크베이트 | 서스펜드 100mm, 립 | 서스펜딩, 수평 자세 |

> 프리셋은 형상과 함께 립, 소재 밀도, 웨이트(무게·위치), 눈·훅 아이·라인 아이 위치까지 해당 루어에 맞게 설정합니다. 화면은 루어 크기에 맞춰 자동으로 확대됩니다.
> 처음 열면 **농어 › 플로팅 미노우**가 표시되며, **↺ 초기화**는 현재 선택한 프리셋 형상으로 되돌립니다.
> 프리셋을 불러온 뒤 형상이나 설정을 바꾸면 하단 상태바에 `(수정됨)`이 표시됩니다.

### 대칭 모드
- **측면 상하 대칭** (기본: 꺼짐) — 위쪽 포인트 이동 시 아래쪽이 자동 미러링
- **상면 좌우 대칭** (기본: 켜짐) — 한쪽 포인트 이동 시 반대쪽이 자동 미러링

### 바디 형태
루어의 기본 치수를 제어합니다.

| 항목 | 설명 | 범위 |
|------|------|------|
| 측면 포인트 수 | 측면 윤곽의 컨트롤 포인트 개수 | 8~32 |
| 상면 포인트 수 | 상면 윤곽의 컨트롤 포인트 개수 | 8~32 |
| 곡선 부드러움 | 베지어 곡선 보간 강도 | 0~1.0 |
| 전체 길이 | 코끝~꼬리 길이 (mm) | 40~250 |
| 측면 높이 | 측면에서 본 세로 높이 (mm) | 8~80 |
| 상면 너비 | 상면에서 본 좌우 너비 (mm) | 6~60 |

> 전체 길이 변경 시 측면과 상면이 동시에 스케일되며, 코끝 위치를 기준으로 조절됩니다.

### 립 (Lip)
- **립 표시** (기본: 꺼짐) — 활성화하면 코끝 아래에 립이 표시됩니다
- **립 길이**: 5~80mm
- **립 각도**: 0~80° (각도가 클수록 깊이 잠행)

### 외관
- **외곽선 두께**: 0~6 (기본: 1)

### 파츠 (드래그로 위치 이동)
눈, 훅 아이, 라인 아이를 추가/삭제하고 드래그로 위치를 조정합니다.

| 파츠 | 설명 |
|------|------|
| 👁 눈 | +/− 버튼으로 추가/삭제, 드래그로 위치 이동 |
| 🪝 훅 아이 | 트레블 훅 연결 위치 |
| 🔗 라인 아이 | 라인(스냅) 연결 위치 |

- 파츠 선택 후 **Delete** 또는 **Backspace** 키로 삭제 가능 (PC)
- **Esc** 키로 선택 해제
- 눈 크기, 훅/아이 크기를 슬라이더로 조절

> **내부 웨이트**는 측면·상면 뷰에 회색 타원으로 표시됩니다. 크기는 납 무게와 같은 부피이며, 측면 뷰에서 앞뒤로 드래그하면 웨이트 위치(10~90%)가 바뀝니다.

### 표시
| 항목 | 설명 |
|------|------|
| 컨트롤 포인트 | 편집 가능한 포인트 표시/숨김 |
| 그리드 | 1mm/1cm 격자 표시/숨김 |
| 무게중심(G) / 부력중심(B) | 측면 뷰에 G·B와 정지 자세의 수직선 표시 (기본: 꺼짐). 정지 상태에서는 B가 G를 지나는 수직선 위에 옵니다 |
| 그리드 선명도 | 5%~100% (기본: 10%) |

### 물리 설정
루어의 재질과 내부 구성을 설정하여 액션을 예측합니다.

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 소재 밀도 | 바디 전체의 평균(유효) 밀도 (g/cm³) | 0.50 |
| 내부 웨이트 | 삽입 무게 (g), 납(11.3 g/cm³)으로 계산 | 5 |
| 웨이트 위치 | 코끝 기준 앞↔뒤 위치 (%), 배 쪽에 놓인 것으로 계산. 측면 뷰의 회색 타원(웨이트)을 드래그해도 조절 | 50 |
| 훅+링 무게 | 훅 아이 1개당 트레블훅+스플릿링 무게 (g) | 1.5 |
| 리트리브 속도 | 감는 속도 1~5단계 (약 0.3 / 0.5 / 0.8 / 1.1 / 1.5 m/s) | 보통(3) |

> 소재 밀도 참고: 발사 0.15 / 오동나무 0.3 / 속이 빈 ABS 바디(유효 밀도) 0.5~0.7.
> 계산은 속이 꽉 찬 바디를 가정하므로, 중공 바디는 재질 밀도(ABS 1.05)가 아니라 바디 전체 평균 밀도를 입력하세요.

### 📊 액션 예측
바디 형태와 물리 설정을 기반으로 자동 계산되는 9가지 예측 수치:

| 항목 | 설명 |
|------|------|
| 부력 상태 | 전체 무게 ÷ 배수량 기준 F(<0.95) / SF(<0.98) / SP(0.98~1.02) / SS(≤1.05) / S (민물 기준) |
| 정지 자세 | 무게중심이 부력중심 바로 아래에 오는 기울기. 플로팅은 수면 흘수선까지 계산 |
| 예상 체적 | 화면의 곡선 외곽선에서 측면 높이 × 상면 너비 타원 단면을 길이 방향으로 적분 (cm³) |
| 예상 무게 | 바디 + 웨이트 + 훅(훅 아이 수 × 훅+링 무게) + 립 (g) |
| 잠행 깊이 | 립 길이/각도와 속도(빠를수록 최대 깊이에 수렴), 정지 자세 반영. 립이 없으면 표층 / 수심 유지 / 침강 속도(cm/s) 표시 |
| 워블 타입 | Wide / Medium / Tight / Super Tight (높이/길이 비율) |
| 워블 폭 | 폭 판정 + 워블 빈도(Hz, 속도 ÷ 바디 높이에 비례) |
| 롤링 경향 | 너비/높이 비율 기반 판정 |
| 캐스팅 비거리 | 공기 저항을 넣은 비행 시뮬레이션 추정 거리(같은 태클 가정): 55 m 이상 장거리, 40 m 이상 중거리 |

> 모든 수치는 설계 비교용 근사치입니다. 실제 값은 도장, 내부 구조, 태클, 수온 등에 따라 달라집니다.

**▶ 액션 미리보기** 버튼으로 2D 애니메이션 확인 가능:
- 측면/상면 전환하여 워블, 롤링, 잠행 깊이를 시각적으로 확인
- 실제 바디 형상이 반영된 애니메이션
- 트레일(잔상) 표시로 움직임 궤적 확인

## 크기 맞춤 기능

측면과 상면의 길이가 다를 경우, 📐 **크기맞춤** 버튼으로 동기화합니다.

| 옵션 | 동작 |
|------|------|
| 측면 기준 맞춤 | 상면의 X축을 측면 길이에 맞춰 스케일링 |
| 상면 기준 맞춤 | 측면의 X축을 상면 길이에 맞춰 스케일링 |

- 코끝(앞부분)을 기준점으로 고정하여 꼬리 방향으로 스케일링
- 자동 동기화: 포인트 추가/삭제/리샘플 시에도 양쪽 길이를 자동으로 맞춤

## SVG 내보내기

상단 **⬇ SVG** 버튼을 클릭하면 현재 루어의 측면/상면 SVG 코드가 생성됩니다.
- 하나의 SVG 파일에 측면(위)과 상면(아래)이 각각 그룹(`side-view`, `top-view`)으로 출력
- 측면에는 립(활성 시)과 눈·훅 아이·라인 아이 파츠도 포함
- 내부 웨이트 위치를 점선 타원(`class="weight"`)으로 측면·상면에 표시
- 클립보드 복사 또는 텍스트 선택하여 사용
- 벡터 그래픽이므로 Illustrator, Inkscape 등에서 추가 편집 가능

## 설계 팁

### 부력 조절
- **플로팅**: 가벼운 소재(발사·오동) 또는 중공 바디 + 적은 웨이트 → 정지 시 떠오름
- **서스펜딩**: 웨이트를 조절해 무게 ÷ 배수량을 0.98~1.02로 맞춤 → 수중에서 멈춤
- **싱킹**: 무게가 배수량을 넘김 → 정지 시 가라앉음 (립 없을 때 침강 속도 표시)
- 훅 아이를 추가하면 훅 무게가 더해지므로 부력이 줄어듭니다

### 워블 특성
- **높이/길이 비율이 클수록** (팻 바디) → 와이드 워블
- **높이/길이 비율이 작을수록** (슬림 바디) → 타이트 / 슈퍼 타이트 워블
- 속도가 빠를수록, 바디 높이가 낮을수록 워블 빈도(Hz)가 높아집니다

### 잠행 깊이
- **립이 길고 각도가 작을수록**(수평에 가까울수록) → 깊이 잠행
- **리트리브 속도가 빠를수록** → 더 깊이 들어가지만 최대 깊이에 수렴
- **머리 숙인 정지 자세**(웨이트 앞쪽) → 립이 빨리 물어 약간 더 깊이

### 캐스팅 비거리
- **무겁고 단면적이 작을수록** (슬림 + 무거움) → 장거리 캐스팅
- **단면적이 클수록** (팻 바디) → 공기 저항으로 비거리 감소
- **무게중심이 뒤쪽일수록** → 꼬리부터 안정적으로 날아가 비거리 증가

## 기술 사양

| 항목 | 내용 |
|------|------|
| 파일 형식 | 단일 HTML 파일 (약 1,400줄) |
| 프레임워크 | 없음 (순수 HTML/CSS/JavaScript) |
| 그래픽 | SVG (편집 뷰) + Canvas 2D (애니메이션) |
| 좌표계 | mm 단위 (그리드: 1mm 보조선, 1cm 주선) |
| 포인트 구조 | 16점 폐곡선 (노즈 0&15, 상부 1-7, 테일 7-8, 하부 8-14) |
| 곡선 보간 | Catmull-Rom → 베지어 변환 |
| 입력 지원 | Pointer Events API (마우스, 터치, Apple Pencil) |
| 반응형 | 768px 이하 모바일, 769-1024px 태블릿, 1025px+ 데스크톱 |
| 히스토리 | 최대 40단계 실행취소 |
